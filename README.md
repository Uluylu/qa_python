# qa_python
Описание тестовых методов:

test_add_new_book_add_invalid_length — Параметризованный тест для проверки граничных условий длины названия. Проверяет, что пустая строка и строка длиной более 40 символов игнорируются системой и не добавляются в словарь.

test_set_book_genre_invalid_genre— Тестирование добавления книги с несуществующим жанром. Если передать жанр, которого нет в списке разрешенных, система должна оставить поле жанра у книги пустым.

test_set_book_genre_valid_genre_True — Проверка успешного присвоения книге жанра из списка разрешенных жанров.

test_set_book_genre_for_not_existent_book — Тестирование возвращения пусПроверка поведения системы при попытке установить жанр книге, которая еще не была создана в коллекции (метод должен возвращать `None`).

test_get_books_with_specific_genre_return_specific_books — Проверка работы фильтра по жанрам. Метод должен возвращать точный список названий книг, подходящих под выбранный критерий.

test_get_books_genre_added_book_has_correct_genre — Параметризованный тест, проверяющий изолированное добавление и связывание пар «книга-жанр». Контролирует динамическую подстановку данных без жесткого хардкода.

test_get_books_for_children_returns_only_children_books — Проверка возрастной фильтрации. Тест контролирует, что из выборки для детей полностью исключаются опасные жанры (такие как «Ужасы» и «Детективы»).

test_add_book_in_favorites_valid_books_add_True — Проверка успешного добавления существующих книг с присвоенными жанрами в список «Избранное».

test_add_book_in_favorites_non_existent_book_False — Проверка того, что несуществующую в основном словаре книгу невозможно добавить в список избранных.

test_delete_book_from_favorites_valid_book_removes_True — Проверка механизма удаления книги из «Избранного» (контролируется, что удаляемая книга исчезает, а остальные остаются в списке).
